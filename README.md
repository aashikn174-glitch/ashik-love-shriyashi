# Shriyashi's birthday letter

A static, mobile-friendly birthday letter made with HTML, CSS, and JavaScript.

## Files

- `index.html` contains the complete website.
- `birthday-photos/` contains the four original photos used in the gallery.
- `netlify.toml` configures Netlify to publish the repository root.

## Deploy with Netlify

1. Sign in to Netlify and choose **Add new project** → **Import an existing project**.
2. Connect GitHub and select `aashikn174-glitch/ashik-love-shriyashi`.
3. Leave the build command blank. Netlify will use the publish directory `.` from `netlify.toml`.
4. Choose **Deploy**. Future pushes to `main` will trigger new deployments.

To update the page later, edit `index.html` or replace a gallery image while keeping its filename, then commit and push to `main`.
